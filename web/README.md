# BeautyOn web

React SPA (Create React App + Craco). See the [root README](../README.md) for how it is built and served with the API in production.

## Local development

```bash
npm install
npm run start
```

Configure `REACT_APP_API_URL` in `.env` (see `.env.example`); for local split dev it is usually `http://localhost:3000/api`.
